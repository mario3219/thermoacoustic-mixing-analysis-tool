# Thermoacoustic Mixing Analysis Tool
A tool I developed together with my partner during our bachelor thesis.

## Goal
The tool imports .TIFF files from ImageJ to calculate mean intensities and can plot flow profiles along with output correlations in multi-dimensional space. This allows the user to visualize whether input parameters are of significance. This tool was also used to find resonance frequencies in the microchip by finding the input parameters returning the smallest half-width peak.
